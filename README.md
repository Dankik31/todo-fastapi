# 📝 To-Do List API (FastAPI)

Простой, но полноценный REST API для управления списком задач, написанный на Python с использованием асинхронного фреймворка FastAPI.

## 🛠 Стек технологий
*   **Python 3.14**
*   **FastAPI** — веб-фреймворк для создания API.
*   **SQLAlchemy (Async)** — ORM для работы с базой данных.
*   **SQLite** — легковесная база данных.
*   **Pydantic** — валидация данных.
*   **HTML/JS** — простой интерфейс для проверки работы API.

## ⚙️ Функционал
*   Создание новой задачи (`POST /tasks`).
*   Получение списка всех задач (`GET /tasks`).
*   Изменение статуса задачи (выполнена/не выполнена) (`PATCH /tasks/{task_id}`).
*   Удаление задачи (`DELETE /tasks/{task_id}`).

## 👨‍💻 Мой вклад в проект
*   **Backend (100% моего кода):** Проектирование структуры базы данных, написание асинхронного API на FastAPI, настройка подключения к SQLite через SQLAlchemy, валидация данных через Pydantic.
*   **Frontend (Демо-версия):** Простой HTML/JS интерфейс для проверки работы API. Код фронтенда был сгенерирован с помощью ИИ, чтобы сэкономить время и сосредоточиться на изучении серверной части. Я понимаю, как он устроен, и могу его доработать при необходимости.

## 🚀 Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Dankik31/todo-fastapi.git
   cd todo-fastapi
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для Mac/Linux:
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите сервер:
   ```bash
   uvicorn main:app --reload
   ```

5. Откройте интерактивную документацию (Swagger UI) в браузере:
   *   API: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
   *   Фронтенд: откройте файл `index.html` в браузере.
